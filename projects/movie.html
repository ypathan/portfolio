Movie Rental Android Application

Project Overview

This was a project I developed for a course in my College. I created an Android Application that provides a platform for users to rent and purchase movies. The application features user authentication, movie browsing, and a seamless rental/purchase process.

Technical Implementation

The project is built using a robust tech stack:

  • Development: Native Java for Android
  • Database: PostgreSQL
  • Authentication: Firebase Authentication
  • User Management: Firebase User Accounts
